# NAMING BRIEF: SCMicroSynth (Proyecto Open-Source / GitHub)

## 1. Fondo (Fundamentos Estratégicos y Propuesta de Valor)
- **Proyecto:** Sintetizador microtonal modular en SuperCollider con motor FM y banco de presets.
- **Audiencia / Arquetipo:** Compositores electroacústicos, exploradores de xenharmonía, artistas sonoros, programadores de audio y usuarios de SuperCollider / DAW.
- **Diferenciador Clave (Propuesta de Valor):** Rompe la limitación del 12-TET estándar ofreciendo 10 afinaciones históricas y microtonales (Partch, Wilson, 31/41/53-EDO) sobre un motor FM modular, liviano y listo para tocar en vivo sin lidiar con bugs de polifonía.
- **Ecosistema:** GitHub (repositorio público open-source, comandos de terminal/SuperCollider, git clone).

## 2. Forma (Restricciones Léxicas y Fonéticas)
- **Idioma:** Inglés universal / Raíz grecolatina accesible internacionalmente.
- **Métricas:** Corto, memorable, fácil de tipear en terminal (`git clone ...`), sin caracteres especiales ni ambigüedad ortográfica.
- **Territorios Conceptuales:**
  1. *Xenharmonía / Microtonalidad:* División del tono, afinación pura, coma, espectro.
  2. *Síntesis FM y Modulación:* Frecuencia, operadores, armónicos, Bessel, espectro dinámico.
  3. *Arquitectura / Modularidad:* Célula, prisma, entramado, motor sonoro.
